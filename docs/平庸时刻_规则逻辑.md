# 平庸时刻 — 规则逻辑提取

> 来源：成交量教学（701s）、板块轮动教学（1009s）、9/14–9/17 四日复盘（3119s），合计约 81 分钟 / 20,000 字
> 说明：本文只提取规则逻辑，不含实现建议。阈值分「原文给定」与「原文未给定」两类，后者必须自行定义。

## 零、他的三条元原则

这三条决定了整套逻辑的性质——**它是一套观察框架，不是信号系统**。

| 原则 | 原话 | 含义 |
|---|---|---|
| 量是证据不是答案 | 「量不是答案，而是证据」 | 单一指标不产生结论，只提供证据权重 |
| 位置决定解释方向 | 「成交量无论放大还是缩小本身没有好坏，但它发生的位置决定你解释的方向」 | 同一指标值在不同位置含义相反，**不可脱离位置解释** |
| 验证优先于信号 | 「后续验证比当日信号更重要」 | 当日读数只是候选，需 T+1/T+2 确认 |

## 一、成交量规则

### 1.1 基础定义

| 概念 | 定义 | 阈值来源 |
|---|---|---|
| 相对量 | 当日量 ÷ 量的 N 日均线（N=5/10/20） | **原文给定**：用量的均线，不看绝对量 |
| 放量 | 相对量 > 1（在量均线之上） | 原文给定方向，**未给倍数** |
| 缩量 | 相对量 < 1 | 同上 |
| 地量 | 「几乎是低量状态」 | **未给定** |

**核心纠正**：放量 ≠ 资金流入。每笔成交都有买方和卖方，成交量表达的是「该价位筹码交换的活跃度」。判断方向要看交换之后**价格站在哪一边**。

### 1.2 量的三重含义

- **参与度** — 愿意交易的人多不多
- **分歧度** — 该价位争议大不大（「买在分歧，卖在一致」）
- **确认度** — 价格运动是否有量支撑

### 1.3 读量的固定顺序（顺序不可乱）

```
1. 趋势  → 上涨 / 震荡 / 下跌
2. 位置  → 低位 / 中段 / 高位
3. 价格  → 涨 / 跌 / 推不动（滞涨）
4. 量能  → 放大 / 缩小 / 异常
5. 验证  → 次日、第三日是否兑现   ★他特别标注
```

### 1.4 五种量价组合（位置决定含义）

| 组合 | 低位 | 中段 | 高位 |
|---|---|---|---|
| **价涨量增** | 突破，观察趋势变化 | 趋势强化 | ⚠️ 巨量 = 分歧明显加剧 |
| **价涨量缩** | 二义：①强势（卖压小，少量即推高）②弱势（参与热度下降）。**判据**：后续有无新增量、是否冲高回落、是否跌破趋势位 |
| **价跌量增** | 长期大跌后 = 恐慌集中释放，可能成底 | — | 下跌趋势中 = 卖压值得重视 |
| **价跌量缩** | 二义：①抛压减弱 ②资金撤离无兴趣。**不等于见底**，需价格结构先改变 |
| **巨量横盘** | 长期下跌后 = 下方承接增强 | — | 连续大涨后 = 上方套牢盘抛压重 |

> 对「巨量横盘」他明确要求：**不要急着贴「吸筹/出货」标签，先看后续价格选哪个方向。**

### 1.5 每日五问（他给的复盘清单）

1. 今天比近期平均量大还是小？
2. 量对应的价格是涨、跌，还是推不动？
3. 信号发生在低位、中段还是高位？
4. 有没有突破/跌破关键位置？
5. 次日、第三日有没有验证？

## 二、板块轮动规则

### 2.1 定义纠正

轮动 **不是**「今天A涨明天B涨」，而是**市场交易重心与相对强弱的迁移**。分三类：

- **行业轮动** — 对经济周期、产业景气度、政策的敏感度差异
- **主题轮动** — 围绕某条产业逻辑/事件催化，上下游被共同交易
- **风格轮动** — 大盘/小盘、成长/价值、高股息/高弹性

### 2.2 三层分析框架

| 层级 | 观察对象 |
|---|---|
| **宏观** | 经济周期、利率、通胀、流动性、汇率、政策催化 |
| **中观** | 行业景气度、订单、价格、库存、利润趋势、估值**预期差** |
| **微观** | 资金流向、交易拥挤度、机构关注度、博弈结构 |

### 2.3 板块强度五维度（核心可编码部分）

| 维度 | 判据 | 阈值 |
|---|---|---|
| **相对强度** | 是否**连续**跑赢市场（非单日） | 未给定连续天数 |
| **上涨广度** | 板块内参与上涨的成分股占比 | 未给定 |
| **成交活跃度** | 是否持续提升 | 未给定 |
| **内部结构** | 能否从龙头扩散到二梯队、上下游 | 未给定 |
| **资金强度** | **分歧后能否修复** ★ | 未给定 |

> 判定强弱的原话：「真正的强不是今天涨得多，而是**持续更强、参与更广、分歧后还能回来**」
> 关键时点：「**不是第一天，而是第一次分歧后**」

### 2.4 主线 vs 一日游

| | 一日游热点 | 真正主线 |
|---|---|---|
| 驱动 | 单一消息刺激 | 逻辑可反复讲清 |
| 参与 | 少数个股 | 板块扩散、梯队清晰 |
| 次日 | 无人接、缺后续验证 | 资金承接与修复 |
| 验证 | 无 | 数据、政策、订单 |

> 「判断主线的关键不是看高潮，而是看**分歧后有没有回流**」

### 2.5 板块生命周期四阶段

```
启动  → 少数核心先动，市场认知不统一
扩散  → 成交活跃，内部参与股增加
分歧  → 强弱分化，核心结构接受检验
切换  → 催化减弱 + 拥挤度提高 → 资金转移
```

**散户典型踩坑点**：在「扩散后期」或「分歧前后」才发现——因为此时全网都在讲，而板块内部中后排已开始掉队、广度在变窄。

### 2.6 市场宽度背离（他给的明确预警）

> **指数上涨 + 参与上涨股票数减少 = 上涨强度在衰减**

具体描述的形态：大盘缩量上涨或缩量横盘，少数权重（大金融）顶着指数，其余个股普遍下跌。

辅助观察：创新高家数、站上均线家数比例。

### 2.7 复盘顺序

```
市场环境（指数/成交/风格）
  → 当前强势持续时间（3天/5天/10天）
  → 板块广度（参与股票数、成交活跃度）
  → 内部结构（核心与梯队是否清晰）
  → 上涨逻辑（政策/景气度/基本面/资金面预期差）
  → 验证（调整后能否修复）
```

**输出形式**：把板块分为「正在增强 / 仍然强势 / 已经衰减」三类，而非预测明天买谁。

## 三、日常复盘的固定流程（四期完全一致）

```
1. 一句话定调          缩量普跌 / 放量普涨 …
2. 指数逐个报点位      开高低收、涨跌幅、相对均线与前高低位置
3. 量能与情绪          成交额、环比%、涨停数、跌停数、炸板率、涨跌家数
4. 归因（固定三条）    「今天为什么这么走，主要是三个方面」
5. 板块拆解            强势/弱势点名 + 资金流向
6. 风险 + 明日推演      三档剧本 + 观察点位
```

### 3.1 他实际使用的情绪指标

| 指标 | 四日实际值 | 含义 |
|---|---|---|
| 两市成交额 | 1.64 → 1.61 → **1.84** → 1.82 万亿 | 环比变化比绝对值重要 |
| 涨停家数 | 55 → 32 → 91 → 47 | 赚钱效应 |
| 跌停家数 | 18 → 34 → 4 → 1 | 恐慌程度 |
| 炸板率 | 高 → 44.8% → 降低 → — | 分歧程度，>45% 视为意见极不一致 |
| 涨跌家数 | 3000/2000 → 1113/4356 → 4152/1182 → 2565/2805 | 市场宽度 |
| 涨幅>5%家数 | — → — → 403 → 193 | 赚钱效应收窄的直接度量 |

> 他给成交量的唯一数值参考：**2万亿/2.5万亿以上赚钱效应好**；跌破 1.7 万亿「热点会同时熄火」。

### 3.2 操作纪律（他反复强调的）

- 不追当天涨幅前三
- 不接昨天涨停的
- 不把一天的强势当成三天的趋势
- 缩量市：**方向比仓位重要，节奏比方向重要**
- 「最怕两头都想要」——既不敢买又舍不得卖最耗损利润
- 分仓建仓，分 2–3 次加

## 四、可编码性分级

### A 级：定义完整，可直接实现

| 规则 | 计算 |
|---|---|
| 相对量 | `V / MA(V, N)`，N=5/10/20 |
| 成交额环比 | `(amt_t - amt_{t-1}) / amt_{t-1}` |
| 涨跌家数比 | `count(pct>0) / count(pct<0)` |
| 市场宽度背离 | 指数收益 > 0 **且** 上涨家数占比下降 |
| 赚钱效应 | `count(pct>5%)` 的日序列变化 |
| 涨停/跌停/炸板率 | 直接统计 |

### B 级：需补一个定义即可实现

| 规则 | 缺什么 |
|---|---|
| 低位/中段/高位 | 需定义位置分档（如 N 日价格分位） |
| 放量/缩量 | 需定义相对量倍数门槛 |
| 分歧后修复 | 需定义「分歧日」与「修复」的判据与观察窗口 |
| 板块广度 | 需定义板块成分（证监会门类过粗，需申万/概念板块） |
| 连续跑赢 | 需定义「连续」天数 |

### C 级：不建议编码

| 规则 | 原因 |
|---|---|
| 三档剧本推演 | 偏强/震荡/转弱穷举全部可能，事后必有一档成立，无指向性 |
| 昨日高低点作支撑压力 | 他本人承认「只是观察参照，不一定有效」 |
| 主力净流入金额 | 券商推算值非真实数据，且他的用法是事后归因 |
| 四阶段实时定位 | 「扩散中期 vs 后期」无判据，事后可辨识、实时不可 |
| 五浪三 | 波浪理论主观性强，与其余量价逻辑体系不一致 |

## 五、这套逻辑的性质与已知缺陷

**性质**：盘后复盘框架。产出是「对盘面的结构化描述」与「明日的观察条件」，**不产出买卖信号**。他本人明确：「复盘的作用是把观察条件提前讲清楚，明天怎么走还是要等市场给出证据。」

**三个结构性缺陷**：

1. **位置判断存在循环依赖** — 整套解释依赖「低位/中段/高位」，但位置要等趋势走完才确定。实时状态下无法知道当前是中段还是高位，而这直接决定同一个放量该读作「趋势强化」还是「分歧加剧」。

2. **验证机制削弱时效** — 「次日/第三日验证」在方法论上正确（承认当日信号不可靠），但代价是确认时已过去 2–3 个交易日的价格变动。

3. **归因不可外推** — 「今天为什么这么走」的三条原因均为收盘后倒推，属描述而非解释，不具备预测效力。

**适用边界**：适合作为**环境上下文**（判断当前市场宽度是扩张还是收缩，据此调整参与度），不适合作为**入场信号**。
