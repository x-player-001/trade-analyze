## ⚠️ 先读：六个口径陷阱

这些踩过坑，前端务必注意：

1. **评分是 1 分制（0~1），不是百分制。** `total_score: 0.6505` 表示 65.05%，要显示百分比自己 ×100。
2. **收益率字段已经 ×100。** `t1_close_ret: -0.92` 就是 −0.92%，直接加 `%` 即可，**不要再乘 100**。
3. **`/api/watch/stats` 的 `hit_rate` 不能直接当胜率对外展示。** 它有幸存者偏差——新入池的票一命中就进分母，没命中的还挂在 `watching` 不计入。真实值要用"窗口走满的世代"算（44.08% vs 公允 39.05%）。要展示可信数字请用 `by_entry_type` 分组值。
4. **K线的 `adjust` 可能被降级。** 请求 `hfq` 时若区间无复权数据，会自动回退原始价并把 `adjust` 标成 `"none(hfq unavailable)"`。**读响应里的 `adjust` 字段判断实际口径**，别假设等于请求值。
5. **`seal_rate`（封板率）只有近 14 天有值**，更早为 `null`（需盘中数据，日线算不出）。画趋势图会断。
6. **行业粒度不统一。** 2026-08-21 起是东财细分行业（「一般零售」「航运港口」），更早是证监会大类（「C39计算机、通信和其他电子设备制造业」，含 658 只票）。**跨期行业对比会混淆**，建议只展示近期。

## 一、选股

### `GET /api/picks/daily`

| 参数 | 说明 |
|---|---|
| `date` | 交易日，默认最新 |
| `version` | `v1`(不看板块) / `v2`(结合板块)，默认 v1 |

返回 `main`（主板 Top20）+ `other`（非主板 Top20）+ `picks`（合并，兼容旧前端），
以及 `market`（当日大盘状态）与 `actionable`（大盘开关是否允许出票）。

单条 `PickOut` 关键字段：`rank` 组内排名、`total_score` 0~1、`factor_scores` 各因子明细、
`reasons` 人类可读理由、`limit_up`/`tradable`（涨停则次日难买入）、
`also_in_versions`（该票还被哪些版本选中，`["v2"]`=双版本共选）。

### `GET /api/picks/dates` → 有选股记录的日期列表

### `GET /api/picks/{code}/detail` → 个股因子历史与被选中记录

## 二、验证

### `GET /api/validation/summary?version=v1&limit=10`
周度汇总。含 `hit_rate_7pct`、`avg_t3_high_ret`、`benchmark_random_hit_rate`（随机对照组）、
`edge_over_random`（**>0 才说明评分排序有效**）。

### `GET /api/validation/daily?date=&version=`
某选股日每只票的 T+1/2/3 回填结果。

> **实测提醒**：v1 近三个月 `edge_over_random` 有 4/6 周为负，选股评分当前**没有正向 edge**。
> 看板若展示这些数字，建议同时给出随机对照组作对比，避免误导。

## 三、K线

### `GET /api/quotes/{code}/kline`

| 参数 | 说明 |
|---|---|
| `start` / `end` | 日期区间 |
| `limit` | 不传 start 时返回最近 N 根，默认 250 |
| `adjust` | `hfq`(默认) / `none` |

**响应**：`bars`（OHLCV）+ `marks`（区间内该股被选中的日期，可在图上标买点）。

**注意**：
- 读 `adjust` 字段判断实际口径（见陷阱 4）。当前库内没有复权数据，`hfq` 实际总是回退。
- `volume` 是**归一化后的「手」**；`volume_raw` 是入库原值（2026-06-15 前单位是「股」，差 100 倍，仅供核对）。
- OHLC 可能为 `null`（复权列在新数据上为空），前端要容错。

## 五、低位首板池

**盯什么**：低位（距 120 日最低收盘 ≤30%）+ 首板（前 60 日无涨停）+ 非 ST 的票，
入池后跟踪 30 个交易日。

**标签**：30 日内是否**再次涨停**。实测公允命中率 **39.05%**，随机基准 19.87%。

### `GET /api/watch`

| 参数 | 说明 |
|---|---|
| `status` | `watching` / `hit` / `expired` |
| `entry_type` | `solo` 孤板 / `consecutive` 连板 —— **连板组命中率 70.81%，是孤板 34.75% 的两倍** |
| `board_group` | `main` / `other` |
| `exclude_broke` | `true` = 剔除已跌破首板开盘价的票 |
| `order_by` | `live_score`(默认) / `entry_score` / `trigger_date` |
| `since` / `limit` | — |

**关键字段**：

- `trigger_vol_ratio` **首板放量倍数，最有预测力**。实测 <2倍 43.1% / 2-4倍 40.2% / 4-6倍 32.6% / ≥6倍 **18.8%**。**越小越好**，建议 ≥4 标黄、≥6 标红。
- `entry_score` 入池评分（只用首板当天信息，入池后不变）；`live_score` 跟踪评分（含连板加成、跌破打折，每日更新）。列表排序用后者，回溯"当初该不该关注"看前者。
- `flat_days` 低位横盘天数 —— **只展示别排序**，实测与命中率相关性≈0。
- `broke_open_date` 非 null = 已跌破首板开盘价，走弱信号，建议置灰。

### `GET /api/watch/stats`
注意 `hit_rate` 的幸存者偏差（陷阱 3），用 `by_entry_type` 更可信。

### `GET /api/watch/{code}`
多一个 `track` 数组（每日 `ret_since` / `amount_ratio` / `is_limit_up`），可画演化曲线。

> ⚠️ 该接口**从外网访问目前返回 503**（`/api/watch` 和 `/stats` 正常）。
> 服务器本机 `curl 127.0.0.1:8000/api/watch/603207` 返回 200 且数据完整，
> PM2 日志里没有该请求记录 —— 是外层代理/CDN 对 `/{参数}` 形态 URL 的处理问题，
> **不是后端 bug**。联调卡住时先本机验证再排查代理。

## 六、低位放量池

**盯什么**：低位（≤15%）+ 放量（超过前 60 日最大量）+ 非 ST。跟踪 10 个交易日。

**标签**：**T+1/3/5/10 收益率**（不是"是否涨停"）。

### `GET /api/lowvol`

| 参数 | 说明 |
|---|---|
| `status` | `watching` / `settled` |
| `first_board` | 只看首板 —— 实测首板 vs 非首板差 2.74pp |
| `exclude_limit_up` | 剔除触发日涨停的（当日难买入） |
| `order_by` | `entry_score`(默认) / `excess5` / `trigger_date` |

**关键字段**：`gain_from_low` 距 120 日低点涨幅（实测单调，越低越好）、
`vol_ratio` 放量倍数（**实测倒 U 型，2-3 倍最优，>5 倍转负**）、
`ret1/3/5/10` 收益、`excess5` **相对全市场超额（判断有无 edge 的关键）**。

### `GET /api/lowvol/stats`

> ⚠️ **当前 `avg_excess5 = −0.83`，跑输市场。** 已核实非实现错误——
> 该池仅覆盖 2026-03 起 6 个月，同期市场累计 −2.97% 是下跌市；
> 回测的 +3.52pp 来自 3.6 年混合行情。**这是样本期不足的典型案例，
> 看板不应把回测数字当作预期收益展示。**

## 七、情绪看板

**盯什么**：连板梯队驱动的市场情绪，判断「当前环境能不能做」。894 个交易日历史。

### `GET /api/sentiment/today?date=` — 看板顶部总览

```json
{
  "trade_date": "2026-09-09",
  "phase": "修复", "stance": "谨慎试仓",
  "zt_count": 48, "zb_count": 27, "seal_rate": 64.0,
  "advance_rate": 0.2027, "height": 5, "ge2": 15, "first_board": 33,
  "phase_hist_ret5": 0.498, "phase_hist_excess5": 0.123, "phase_hist_days": 444,
  "tiers": [
    {"boards": 5, "count": 1,  "codes": ["..."], "names": ["..."]},
    {"boards": 3, "count": 4,  "codes": [...]},
    {"boards": 2, "count": 10, "codes": [...]},
    {"boards": 1, "count": 36, "codes": [...]}
  ]
}
```

- **`phase`** 六阶段之一：冰点 / 启动 / 主升 / 高潮 / 退潮 / 修复（已做 2 日确认，不会天天跳）
- **`stance`** 操作倾向：空仓观望 / 可以进场 / 持股待涨 / 减仓兑现 / 离场规避 / 谨慎试仓
- **`phase_hist_*`** 该阶段历史上的后续表现（实测 894 天）——建议展示成
  「当前：修复 · 历史该阶段 T+5 +0.50%（超额 +0.12），样本 444 天」，
  比只显示一个标签有用得多
- **`advance_rate` 晋级率**（昨日连板池今日续板比例）是**最核心的指标**
- **`tiers`** 连板梯队，每档带前 10 只个股，可画金字塔

### `GET /api/sentiment/trend?days=60`
历史序列，**按日期升序返回**，前端可直接画图。含 `zt_count`/`zb_count`/`seal_rate`/
`height`/`ge2`/`advance_rate`/`phase`。可用 `phase` 给折线加阶段色带。

### `GET /api/sentiment/industry?date=&min_zt=3&limit=20`
行业热度榜。热度分 = `0.35×涨停数 + 0.25×最高板 + 0.25×梯队档位数 + 0.15×二板宽度`，
每行业当日涨停 <`min_zt` 不参与排名。返回该行业涨停个股（前 10）。

### `GET /api/sentiment/phases`
各阶段历史统计，可做看板的「阶段说明」浮层：

| 阶段 | 天数 | 占比 | 均涨停 | 均高度 | 均晋级率 |
|---|---|---|---|---|---|
| 高潮 | 6 | 0.7% | 374.2 | 10.3 | 0.304 |
| 主升 | 122 | 13.6% | 78.5 | 7.6 | 0.279 |
| 启动 | 189 | 21.1% | 54.3 | 5.9 | 0.230 |
| 修复 | 444 | 49.7% | 54.7 | 5.0 | 0.210 |
| 冰点 | 27 | 3.0% | 27.1 | 4.4 | 0.200 |
| 退潮 | 106 | 11.9% | 44.9 | 4.2 | 0.170 |

### ⚠️ 情绪模块的使用边界（实测结论）

- ✅ **可用作风险开关**：冰点后续 T+5 超额 **−1.63**、退潮 **−0.65**（894 天样本）。
  这两个阶段合计占 15% 的交易日，避开它们能改善整体表现。
- ✅ **阶段切换点信号更强**：进入主升 T+5 **+1.16%** vs 处于主升 +0.38%，差 3 倍。
- ❌ **不要暗示"某阶段适合打板"**：实测各阶段涨停股次日收益都在 **1.8~2.0%**，
  阶段对打板**完全没有区分度**（冰点甚至排第二）。
- ⚠️ 高潮仅 6 天、冰点 27 天，这两档统计上很薄，展示时不宜过度解读。
